# Dr. Gayatri M. Phade — Professional Academic Portfolio

A modern, responsive single-page portfolio website built with **React + Vite** for **Dr. Gayatri M. Phade**, Professor and Head of the Department, Electronics & Telecommunication Engineering at Sandip Institute of Technology and Research Centre (SITRC), Nashik.

---

## ✨ Features

- **Hero Section** — Professional introduction with profile image and call-to-action
- **About** — Bio, designation, research interests, and key stats
- **Qualifications** — Academic degrees displayed in an interactive timeline
- **Awards & Recognition** — Searchable list of 26+ awards with real-time keyword filtering
- **Patents** — 9 patents including Speech Synthesizer, Robotic Arm, and Milk Analyzer
- **Research Areas** — IoT, Embedded Systems, Women Entrepreneurship, and more
- **Publications** — Filterable publications with journal/conference badges
- **Workshops & Seminars** — Accordion-style event listings
- **Contact** — Form and contact details
- **Responsive Design** — Fully responsive across mobile, tablet, and desktop
- **Searchable Filter** — Dynamic search bar for Awards and Qualifications

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) v18 or higher
- npm (bundled with Node.js)

### Install Dependencies

```bash
npm install
```

### Run the Development Server

```bash
npm run dev
```

This starts the Vite dev server with Hot Module Replacement (HMR). Open the URL shown in your terminal (usually `http://localhost:5173`).

### Build for Production

```bash
npm run build
```

The production-ready files are output to the `dist/` directory.

### Preview the Production Build

```bash
npm run preview
```

## 🌐 Deploying to Vercel

This project is ready for GitHub-based deployment on [Vercel](https://vercel.com).

### Vercel Build Settings

- **Framework preset:** Vite
- **Install command:** `npm install`
- **Build command:** `npm run build`
- **Output directory:** `dist`

### Git-based Deployment

1. Push this project to a GitHub repository.
2. Import the repository in Vercel.
3. Keep the default Vite settings, or confirm the settings listed above.
4. Deploy. Vercel will rebuild the site on every push.
